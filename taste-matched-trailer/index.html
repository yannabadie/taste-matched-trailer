How to read the demonstration · static guide
  1. Start with a book brief and public cultural references. Resolve uncertain titles before using their identifiers.
  2. Read the movie affinities actually returned by Qloo. Missing affinity is not zero, and association does not establish commercial performance.
  3. Inspect which references the selection rule retained and how each is linked to the four creative plans. Framing, words, pacing and sound remain editorial interpretations.
  4. Review the sources and limitations, then download the received document. A dated recording is distinct from a new live analysis; neither is a rendered video.

This guide remains readable if the Mac or gateway is unavailable. It does not contain or replace the Qloo response. Opening the recorded example requires that gateway; a new live analysis additionally requires the protected Qloo and model workflow.
